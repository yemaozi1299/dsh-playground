# 一个组合只挂一个提供方：重复挂不报错，后挂的静默失效

用户原以为两个实现都写进 `cordis.yml` 会报错。2026-10-09 的离线实测更正了这一点：不报错，先挂的生效，第二个被静默忽略；只有同一个插件里 `provide` 两次才会抛 `service "probe" has been registered`。

**Evidence**：`tmp/greeter-check.ts` 的三组对照（只挂 random / 只挂 fixed / 两个都挂）输出。

**Implications**：静默失效比报错更难查，所以"配置里多挂了一个实现"要进排查清单。同时这也是一条方法论证据：**他自己写下的结论也要实测**，记在笔记里的"会报错"就是反例。
