一、README 要回答的三件事

这个包给谁、怎么装；模型会看见什么；哪些坑接手的人必须知道。门禁按 packages/*/*/package.json 逐个找 README，缺了直接报 missing package README。结构由 scripts/doc-standard.spec.ts 与三个 verify-package-readme-* 脚本检查。

二、kind 由事实推出，不是自己挑

事实kind模板
packages/README.md 或 packages/<组>/README.mdpackage-grouppackage-group.md
manifest 声明了 dsh.bundle.patchpackage-bundlepackage-bundle.md
在 doc-standard.spec.ts 的 PACKAGE_LIBRARIES 清单里package-librarypackage-library.md
其余：有 apply 或默认导出 servicepackage-referencepackage-reference.md

hello-greet 在 lesson 0003 加了 dsh.bundle.patch，所以是 package-bundle。frontmatter 只写 description 与 kind；name、audience、tags、i18n 都会被拒。

Summary、Table of Contents、Dev Note 三样是 doc-standard.spec.ts 的硬要求。Summary 超过 100 词会报 Summary has N words; the limit is 100。

四、Model Experience

位置固定：## Model Experience 是最后两个 H2 的倒数第二个，## Known Limitations and Deferred Work 是最后一个。两种写法，二选一。

结构化条目

## Model Experience

### 条目名

#### What the model sees

一段：模型收到的字段、字面文本、结果。

#### Token effect

一段：每次请求的固定成本，加一次调用带来的增量。

#### KV Cache effect

一段：是否在可复用前缀里，什么改动会让缓存失效。

三格标题逐字固定，顺序固定；每个条目至少有一处具体字面量，三种任选：反引号里的字段名、带标题的 ##### 加 ```markdown 原文块、工具目录的锚点链接。只有形容词过不了。

条目标题里出现 schema 这个词，门禁要求链到 ../../../docs/tool-catalog.md#<锚点>。工具目录只从固定的一批插件生成，目录里没有的工具，标题就别写 schema。

一句话形式

## Model Experience

None, as <理由>。

#### KV Cache effect

一段。

也可以以 Indirectly, through … 开头。这种形式要求包名先登记进 脚本的 SENTENCE_MODEL_EXPERIENCE，并写清审计理由。只写 None. 会被拒。

三格各写什么

字段回答的问题greet 的答案
What the model sees模型收到的字面内容是什么工具名 greet、description、name 必填、language 的 enum 是 zh / en、返回一段文本
Token effect每次请求固定花多少，调用再加多少schema 每次请求都发；一次调用多一条短结果
KV Cache effect它在可复用前缀里吗；什么改动会让旧缓存失效schema 在前缀里；增删改这个包都会换前缀；调用与结果只追加

五、Known Limitations

写持久的消费者缺口和维护者约束：缺了什么、后果是什么。至少一条 - 开头的条目，门禁只查这一条。日常清理写进源码 TODO 或 Agent Note。确实没有限制，就登记进 scripts/verify-package-readme-limitations.ts 的 NO_LIMITATIONS，不要留一个空节。

六、命令

pnpm run verify-package-readme-summaries          # Summary 词数
pnpm run verify-package-readme-model-experience   # Model Experience 结构
pnpm run verify-package-readme-limitations        # Known Limitations
pnpm exec vitest run scripts/doc-standard.spec.ts # 全仓库包 README 的 kind / 骨架
pnpm run verify-md-wrap                            # 一段一行，不许硬折行
pnpm run verify-md-links                           # 相对链接与锚点
